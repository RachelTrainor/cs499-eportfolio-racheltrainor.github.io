Algorithms & Data Structures

This section presents my algorithms and data structures enhancement of the Weigh To Go Android application.

Download Original Artifact Download Enhanced Artifact

Enhancement Narrative

For this enhancement, I continued working with my Weigh To Go Android application that I originally created in CS 360: Mobile Architecture and Programming. The application allows users to record their weight, set a goal weight, and receive SMS notifications. I continued using this artifact because it gave me several opportunities to improve how the application uses the data it collects.

For the algorithms and data structures enhancement, I added a WeightRecord class and used an ArrayList to organize the user's weight records. I also added sorting options that allow records to be sorted from oldest to newest, newest to oldest, lowest to highest weight, and highest to lowest weight. In addition, I created calculations for starting and current weight, total weight lost or gained, average weight change, recent weight changes and trends, and progress toward the user's goal. I also created a separate progress screen with a progress bar.

Before this enhancement, the weight log mainly allowed users to save, edit, display, and delete their records. I wanted the application to do more with the information that was already being stored instead of only displaying it back to the user.

I used an ArrayList<WeightRecord> after retrieving the records from the database. This allows the application to sort and analyze the records without changing how they are stored in the database. I also made sure dates are compared as actual dates instead of only sorting the date text. This makes the sorting more reliable when different date formats are used.

I added calculations that move through the weight records to provide more useful information. The application calculates the average change between consecutive entries, compares the two newest records to determine the most recent change, and uses recent records to identify whether the user's weight trend is increasing, decreasing, or staying stable. Goal progress is also calculated as a percentage and displayed using a progress bar.

These changes made the stored weight information more useful to the user. Instead of only seeing individual records, the user can now see how their weight has changed over time and how much progress they have made toward their goal.

This enhancement demonstrates the course outcome related to designing and evaluating computing solutions using algorithmic principles. I used data organization, sorting, traversal, and calculations to turn stored records into useful information. The ArrayList works well because the number of weight records can change over time, while the WeightRecord class keeps each record organized. The comparison and sorting logic also allows the same data to be viewed in different ways.

This enhancement also helped improve the overall quality of the application. Instead of placing every feature on the weight log screen, I created a separate progress screen for the analysis. This keeps the interface from becoming too crowded while still giving users access to more detailed information.

Working on this enhancement helped me better understand how algorithms and data structures can make stored data more useful. One challenge was making sure the records sorted correctly when users entered dates in different formats. I also had to test the calculations with different weight records to make sure the results were accurate. This showed me the importance of considering user input when designing algorithms.

I also learned that adding more functionality does not mean every feature needs to be placed on the same screen. Moving the progress information to its own screen made the application less crowded and easier to use. Testing the sorting and calculations gave me more experience organizing, sorting, and analyzing data while still considering the user experience.
